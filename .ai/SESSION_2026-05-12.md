### Build & Toolchain

- Cihaza **native** build çalışmaz: cihazda Qt dev headers, qmake, cmake yok
- **Cross-compile Docker** stratejisi: `smb-q6r-builder:focal-arm64`
  imajı Ubuntu 20.04 (glibc 2.31) + arm64 multiarch + Qt 5.12.8 dev
- Bu **cihazın sistem Qt'siyle ABI-uyumlu** binary üretir; vendor 5.15.10
  hiç dokunulmaz
- Host'taki Noble-arm64 toolchain `crossbuild-essential-arm64` +
  `qtbase5-dev:arm64` ilk kurulduydu ama **artık kullanılmıyor**;
  Docker yolu kalıcı seçildi (glibc 2.34 sembolu sorununu çözmek için)
- Cihaza sadece **stripped** binary deploy edilir (~75 KB);
  build/ asla cihaza gitmez (disk kısıtı)

## Bilinmesi Gereken İncelikler

- **HwIo singleton fd'leri:** /dev/leds, /dev/pwm, /dev/buttons,
  /dev/buttonstop **bir kere açılır**. Hayatın boyu açık kalır. Yeniden
  açma driver state'ini bozuyor (Errno 22). HwIo singleton bunu garanti eder.
- **Buzzer cmd=0:** "mute" — ama bazen `EINVAL` döner (zaten kapalıyken).
  BuzzerController::silence() bunu cmd=1, val=0 fallback ile handler eder.
- **Backlight 0 yazma:** Ekranı söndürür ve kullanıcı kör olur. UI slider
  minimum 5'e clamp ediliyor.
- **input grup üyeliği:** Tronlong eklendi ama mevcut X oturumu eski
  group set ile başlamış. Plugdev üzerinden event[0-9]* RW olduğu için
  şu an problem yok; ileride başka uygulamalar için relogin/reboot lazım.
