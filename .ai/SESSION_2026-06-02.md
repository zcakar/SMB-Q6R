### 2. Live Connect Denemesi — İki Bug Çıktı (`523c970`)

İlk Connect tıklamasında:

- **stateChanged sinyali UI'ya hiç ulaşmadı** — log'da
  `QObject::connect: Cannot queue arguments of type 'smbq6r::PlcLink::State'`.
  Queued connection için enum'lar manuel register lazım:
  `qRegisterMetaType<PlcLink::State>("smbq6r::PlcLink::State")` ctor'a
  eklendi. Çözüldü.
- **Kullanıcı butonu birkaç kez tıklayınca** her seferde yeni session
  açılıyor, öncekini koparıyor. `doConnect()` artık aynı URL'e zaten
  bağlıysa erken döner (idempotent).

Ayrıca network setup:
- `scripts/configure-plc-network.sh`: pendant `eth1`'ine `192.168.0.245/24`
  alias ekler (PLC 192.168.0.2 ile aynı subnet), netplan'da persist
  eder. Live `ip addr add` ile anında çalışır.

Yeni binary deploy. Tek tık Connect → **yeşil "PLC: Connected"**.

### 3. Browse Namespace + Double-Free Fix (`ef3ad86`)

`PlcLink::browseNamespace(maxDepth=5, maxNodes=250)` — Objects
folder'dan başlayarak BFS. Her node `nodeDiscovered` signal'ı + qInfo
log line emit eder. Connect başarılı olduğunda auto-trigger.

İlk denemede `free(): double free detected in tcache 2` → SIGABRT.
Sebep: `UA_BrowseRequest.nodesToBrowse[0].nodeId = p.id` shallow
assign, sonra hem `UA_NodeId_clear(&p.id)` hem
`UA_BrowseRequest_clear(&req)` aynı string identifier'ı free etti.
Fix: `UA_NodeId_copy(&p.id, &req.nodesToBrowse[0].nodeId)` ile deep
copy — her iki taraf kendi memory'sini yönetir.

**Browse sonucu — KEY DISCOVERY**:

```
ns=4;s=|plc|MAT LC-C07            ← PLC device path
ns=4;s=|var|MAT LC-C07.Application ← Application root
```

Yani variable node id formatı:
`ns=4;s=|var|MAT LC-C07.Application.<GVL>.<Var>`. Symbol XML'deki
proje adı (`CodeSysSP20_3Axis_CNC_SMB_LAZER_...`) **node id'lerde
geçmiyor** — sadece PLC device adı.

### 6. KeyCell Layout Fix (`a8518b4`)

Kullanıcı: "Hardware tab'ında hizalama bozuk". Screenshot'tan görünen
matrix keypad hücrelerinin içindeki üç metin (üst axis label + orta
büyük +/- glyph + alt code text) anchors-based pozisyonlanıyordu;
hücre 60 px'e indiğinde büyük glyph üst/alt etiketle örtüşüyordu.

Çözüm: hücrenin içi tek `Item` + üç child Text — `parent.height *
{0.26, 0.48, 0.26}` fraksiyon yükseklikleri, font size'lar
`Math.max(min, Math.round(height * %))`. Tüm hücre boyutlarında
overlap garanti olmaz.

## Bilinen Sorunlar (Devam Edecek)

1. **Struct node monitoring**: `IoConfig_Globals.Device` ve diğer
   T_CAADiagDeviceDefault tipindeki node'lar direkt subscribe
   edilemez. Phase 2'de child field discovery + per-field subscribe
   eklenecek.
2. **Reconnect-on-disconnect yok**: bağlantı koparsa kullanıcı manuel
   Connect basmak zorunda. Phase 2 başında exponential backoff retry
   eklenecek.
3. **Heartbeat yok**: pendant↔PLC arasında watchdog protokolü henüz
   yok. Phase 2'de zorunlu — bkz `PLC_INTEGRATION.md` §6.
4. **On-screen klavye yok**: URL field'ı editlemek için USB klavye
   gerekiyor. Düşük öncelik; default URL setup zamanında bir kez
   ayarlanır, sonra unutulur.
5. **QML Connections deprecation warning**: Qt 5.15'te `onSignalName:`
   syntax'ı yerine `function onSignalName() { }` öneriliyor. Çalışıyor
   ama warning. Düşük öncelik kozmetik.
